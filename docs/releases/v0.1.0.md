# FlowSentry v0.1.0

The first public release of FlowSentry: self-hosted monitoring and incident management for n8n workflows.

## Included

- n8n API connections, workflow discovery, execution polling, and Error Workflow webhook ingestion.
- Searchable execution history, redacted failure details, and expandable workflow stages derived from actual nodes.
- Grouped incidents with severity, assignment, comments, and acknowledge/investigate/resolve/reopen actions.
- Email, Telegram, and webhook notifications with rules, cooldowns, delivery retries, and delivery history.
- Overview, workflow health, analytics, workspace roles, invitations, audit history, and account/session settings.
- Responsive interface with light and dark themes, keyboard navigation, and reduced-motion support.
- Durable PostgreSQL outbox, migrations, retention, health checks, and backup/restore tooling.

## Install using published images

Download and extract `flowsentry-v0.1.0-install.tar.gz` from this release. It includes Compose files, documentation, and the configuration generator; a local source build is not required.

```sh
python scripts/configure.py
docker compose -f compose.yaml -f compose.release.yaml pull
docker compose -f compose.yaml -f compose.release.yaml up -d --no-build
```

Open http://localhost:3100 and create the first owner account. Use Docker Compose v2. Images support Linux AMD64 and ARM64 hosts:

- `ghcr.io/abdullahzahid123/flowsentry-backend:v0.1.0`
- `ghcr.io/abdullahzahid123/flowsentry-web:v0.1.0`

The backend image is shared by the API, migration, worker, and scheduler services. `SHA256SUMS` covers the installation archive. GitHub also provides the complete tagged source as ZIP and tar.gz downloads.

## Verification and limits

Release publication requires backend tests, frontend build/type checks, and the production dependency audit to pass. Local acceptance also exercised n8n 2.45.7, SMTP capture, duplicate delivery, API restart durability, and database backup/restore. The optional live n8n contract test requires a configured instance and is skipped by standard CI.

This is an early monitoring release. Production TLS/network configuration, a real SMTP service, and notification destinations remain operator responsibilities. Real Telegram delivery has not been verified. Native retry/recovery, maintenance windows, SLA escalation policies, and additional providers are outside this release. Read the deployment and release-coverage guides before a production installation.

FlowSentry is independent of n8n and licensed under Apache 2.0.
